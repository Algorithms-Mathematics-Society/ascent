# Legal publication and private status access: 14 September 2026

This release adds versioned privacy and terms pages, current consent records,
server-verified Turnstile checks and candidate status access through one-use
emailed links. Candidates do not create accounts. The existing copy cleanup
removes em dashes across `src` and `public`, with clearer event descriptions.

## Verification

- 167 unit/route tests passed, including invalid/missing Turnstile configuration,
  action and hostname checks, provider outages, signed-token tampering and expiry.
- 22 registration/admin concurrency tests passed against isolated Firestore,
  including 40 distinct registrations, competing duplicates, capacity limits,
  current terms/privacy acceptance and rejection before writes. The three new
  consent rejection cases were rerun after correcting their test Host headers.
- 26 email/status integration tests passed with actual Firestore and mocked
  Resend. Ten simultaneous uses of one access link create exactly one session.
  Known and unknown addresses receive identical request responses; only known
  addresses receive email. Coverage includes deduplication, changed/deleted
  recipients, private response fields and ambiguous delivery outcomes.
- 20 Firestore rules tests passed, including token and rate-limit collections.
- 44 desktop/mobile page checks passed, including nine admin authentication
  redirects, reminder pagination, legal navigation, footer links and disabled
  forms with missing configuration. No horizontal overflow or runtime errors.
- A separate mobile browser test exercised the real token exchange, decision
  refresh, session closure, fragment removal and rejection of link reuse.
- Production compilation, TypeScript, lint and `git diff --check` passed.

Provider APIs were mocked in tests. Browser tests use synthetic local emulator
records, not real applicants. Live Turnstile challenges and email delivery remain
activation checks after keys and a verified sender are configured.

laboratory runs, not production field measurements. Turnstile keys were blank;
